# HabitForge – Smart Habit Tracker

HabitForge is a smart habit tracking web application designed to help users build consistent daily routines and achieve long-term goals through progress tracking, analytics, and gamification.

---

## Inspiration
Many people struggle to maintain daily habits like studying, exercising, or reading because they cannot easily track progress or stay motivated. HabitForge was created to make habit building simple, visual, and engaging.

---

## What it does
HabitForge allows users to:

- Add and track daily habits
- Maintain streaks by marking daily completion
- View analytics through charts
- Earn achievement badges
- Compete via leaderboard
- Switch between dark and light modes

The platform helps users stay disciplined and motivated.

---

## How we built it
HabitForge is built as a lightweight web application using:

- HTML for structure
- CSS for styling and responsiveness
- JavaScript for functionality
- Chart.js for analytics visualization
- Browser LocalStorage for data storage

The application runs fully in the browser without requiring a backend server.
